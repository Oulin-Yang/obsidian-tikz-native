# TikZ Native 兼容性示例

## circuit-cut

```tikz
% !TeX program = lualatex
\begin{tikzpicture}[>=stealth,every node/.style={font=\small},v/.style={circle,draw}]
\node[v] (x) at (0,1) {$x$}; \node[v] (y) at (3,1) {$y$};
\draw[->,thick] (x)--node[above] {$u$}(y);
\draw[->] (y) to[bend left=45] node[below] {path} (x);
\node at (1.5,-.8) {$x\in M$: circuit};
\draw[fill=blue!8] (8,1) ellipse (1.4 and 1.1);
\node[v] (xx) at (5.3,1) {$x$}; \node[v] (yy) at (7.3,1) {$y$};
\node at (8.4,1.4) {$M$};
\draw[->,thick] (xx)--node[above] {$u$}(yy);
\node at (7.3,-.8) {$x\notin M$, $\omega^+(M)=\varnothing$};
\end{tikzpicture}

```

## basic

```tikz
% !TeX program = pdflatex
\begin{tikzpicture}\draw[->,red] (0,0)--(2,1);\node at (1,0) {$x^2$};\end{tikzpicture}
```

## libraries

```tikz
% !TeX program = lualatex
\usetikzlibrary{arrows.meta,calc,positioning,decorations.pathmorphing,patterns,intersections}
\begin{tikzpicture}\node[draw,pattern=north east lines] (a) {A};\node[draw,right=of a] (b) {B};\draw[-{Stealth},decorate,decoration=snake] (a)--(b);\end{tikzpicture}
```

## graphdrawing

```tikz
% !TeX program = lualatex
\usetikzlibrary{graphs,graphdrawing}
\usegdlibrary{layered}
\begin{tikzpicture}\graph[layered layout,nodes={draw,circle}]{a -> {b,c} -> d};\end{tikzpicture}
```

## pgfplots-3d

```tikz
% !TeX program = lualatex
\usepackage{pgfplots}\pgfplotsset{compat=1.18}
\begin{tikzpicture}\begin{axis}\addplot3[surf,samples=8,domain=-2:2]{x^2-y^2};\end{axis}\end{tikzpicture}
```

## tikz-cd

```tikz
% !TeX program = pdflatex
\usepackage{tikz-cd}
\begin{tikzcd} A \arrow[r,"f"] \arrow[d] & B \arrow[d] \\ C \arrow[r] & D \end{tikzcd}
```

## circuitikz

```tikz
% !TeX program = pdflatex
\usepackage[european]{circuitikz}
\begin{circuitikz}\draw (0,0) to[R=$R$] (3,0) to[C=$C$] (3,2);\end{circuitikz}
```

## complete-document

```tikz
% !TeX program = pdflatex
\documentclass[tikz,border=4pt]{standalone}
\begin{document}\begin{tikzpicture}\draw (0,0) circle (1);\end{tikzpicture}\end{document}
```

## multiple-pages

```tikz
% !TeX program = pdflatex
\documentclass[tikz,multi,border=3pt]{standalone}
\begin{document}\begin{tikzpicture}\draw (0,0)--(1,1);\end{tikzpicture}\begin{tikzpicture}\draw (0,0) circle (1);\end{tikzpicture}\end{document}
```
